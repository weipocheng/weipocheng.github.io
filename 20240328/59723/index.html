使用kubeadm安裝Kubernetes集群

發表於 2024-03-28 更新於 2025-07-23 分類於 DevOps 閱讀次數：
文章字數： 4.1k 所需閱讀時間 ≈ 4 分鐘

前言

原本公司有一個dev環境

最近需要額外再開一個stage環境給同仁測試

k8s集群需要和dev環境分開了

所以需要另外再建一個新的集群

趁這次機會把建立的步驟記錄下來以免以後忘記😆

建立環境

預計會在GCP上建立VM並部屬k8s集群

以下是部屬資訊:

k8s-master:

  • OS: Ubuntu 20.04.6 LTS
  • CPU: 2C
  • MEMORY: 4G
  • DISK: 20G SSD

k8s-node-1:

  • OS: Ubuntu 20.04.6 LTS
  • CPU: 2C
  • MEMORY: 4G
  • DISK: 20G SSD

node數量和配置可再依照需求自行調配
